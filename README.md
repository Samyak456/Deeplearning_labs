1. Open the folder for the assignment you want to explore.
2. Read the practical document or assignment-specific README.
3. Open the Jupyter Notebook.
4. Install the dependencies required by that notebook.
5. Run the notebook cells in order.

Some notebooks may require downloading datasets or model weights and may need an internet connection or GPU for faster execution. Refer to the individual notebook for its specific setup.
